# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-11
### Added
- Complete migration from legacy Swing GUI to Web-based architecture.
- Full-stack integration with Java Spring Boot API and Vanilla JS frontend.
- JWT-based authentication system with Role-Based Access Control (RBAC).
- Database migration to PostgreSQL (hosted on Supabase).
- Render deployment configuration (`render.yaml`) for Dockerized backend.
- Vercel deployment configuration (`vercel.json`) with secure headers and API proxy rewrites.
- GitHub Actions CI workflow for backend Maven builds.
- Issue and Pull Request templates.
- Architectural and API documentation.
